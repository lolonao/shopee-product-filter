# Shopee Product Prospector 改修計画 (2025/09/10)

## 1. プロジェクト名の決定

- **新プロジェクト名:** `Shopee Product Prospector`
- **リポジトリ名:** `shopee-product-prospector`

## 2. プロジェクトの目的の再定義

このアプリケーションの主な役割は、ユーザーが提供したShopeeの商品リストHTMLから有望な商品を絞り込み、後続の「検索クエリ生成アプリ」に渡すためのデータをCSV形式で出力すること。最終的な仕入先の特定や管理は、このアプリの範囲外とする。

## 3. 大規模な機能改修計画

上記の目的に特化するため、以下の機能改修を行うことで合意。

### 3.1. 機能の方向性

- **廃止:** ソーシング管理機能（ステータス、メモなど）
- **新設:** 出力リストの選別機能（除外フラグ、レコードの物理削除）

### 3.2. データベース (DB) スキーマの変更

`ProductBasicItem` モデルを以下のように変更する。

- **削除する項目:**
    - `sourcing_status`
    - `sourcing_notes`
    - `status_updated_at`
- **追加する項目:**
    - `is_excluded: bool = Field(default=False)` (出力から除外するかどうかのフラグ)

### 3.3. APIの変更

- `PUT /products/{id}/sourcing-info` エンドポイントは**削除**する。
- `PUT /products/{id}/toggle-exclusion` のような、`is_excluded` フラグを切り替えるエンドポイントを**新設**する。
- `DELETE /products/{id}` という、レコードを完全に削除するエンドポイントを**新設**する。

### 3.4. Streamlit UIの変更

- ソーシング関連のUI（プルダウン、メモ欄）は全て**削除**する。
- 検索結果の各商品の横に、「出力から除外」するためのチェックボックスかボタンを**追加**する。
- 各商品の横に、レコードを物理的に削除するための「削除」ボタンを**追加**する（※要 確認ダイアログ）。
- 検索条件に「除外済み商品を表示/非表示/全て」を選択するフィルターを**追加**する。
